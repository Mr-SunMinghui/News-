# snapshots

对每个查到并核验的来源优先保存可检索的本地文字快照。许可允许时，保存实际取得的正文为 UTF-8 Markdown/纯文本，保留段落顺序和来源元数据；每次观察另存新文件，不覆盖历史版本。

多个来源的事实可以汇总到事件目录的 `事实汇编.md`，注明每项来源和统计口径，使用自己的语言整理，方便离线查阅。

全文未保存时，仍创建尽可能详尽的“事实汇编/摘要型文字快照”，包括事实、数字、时间、统计口径、结论归属、必要短引文、原始 URL、获取时间/时区、获取方式和保存范围。用自己的语言整理，不得把汇编伪装成原文。页面不可访问时只能记录本次观察和其他可核验材料，不得伪造快照。

哈希只对实际保存在本地的真实字节计算，并注明算法、文件路径与计算时间。摘要笔记只能比较摘要，不得据此声称原文有逐字改动。
