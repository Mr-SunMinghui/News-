# 实践档案

浏览事件请先打开仓库根目录 [速览网页](../速览.html)，或点击事件目录中的 `速览.html` 查看该事件的时间线。新增事件时复制 `templates/event/速览.html` 并替换字段与时间线条目；同时更新根目录速览页和事件索引，保证入口不遗漏。

每个事件位于 `events/<event-id>/`，使用 `templates/event/` 的文件结构。新增档案前先查 `事件索引.md` 和现有 ID，避免重复。每项资料注明时区、来源和核验时间；未知值写 `unknown`。状态与来源可访问性分开维护。仅记录真实取得的报道版本和差异。

事件状态、证据状态、隐私版权、增量巡检和重试规范见仓库根目录 `AGENTS.md`。本阶段模板不自动执行抓取、散列或差异计算。
