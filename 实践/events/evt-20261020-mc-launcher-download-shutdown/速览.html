国内《我的世界》第三方启动器关闭游戏本体下载功能

2026年10月20日下午起，PCL 关闭下载功能，HMCL（预览版）与 PCL CE 按中国大陆地区限制《我的世界》本体/整合包下载、安装功能；三款均未显示已安装版本无法启动。具体法律依据、监管文书及“未成年私服充值被家长举报”的起因仍待核实；截至10月21日20:00，未见恢复下载的正式版本或监管机关公开文书。

事件时间线

2026-10-20 15:01

PCL 2.99.0.0 关闭 MC 下载

版本说明称“为遵守相关法律法规，PCL 不再提供 MC 下载功能”，并称“与网易微软麻将无关，中国式家长很神奇吧”。未说明具体条款、机关或恢复时间。（S-001）

2026-10-20 15:22—16:50

HMCL 提交、合并 PR 并发布预览版

PR #7017《在中国大陆地区禁用游戏下载功能》提交，16:37 合并，16:50 发布预览版 3.17.0.362。代码以时区、国家码、GeoID 与 IP 判断大陆，判断失败时按大陆处理，禁用版本下载页及一个附加内容下载列表页；稳定版仍为 3.16.4。（S-003、S-004）

2026-10-20 16:26

“所有启动器被封禁”报道出现

游侠网称“国内所有的MC启动器都遭到了封禁”。该文发布时 HMCL 尚未发版、PCL CE 尚未发版，标题属过度概括；其“请勿正常启动”说法未指向 PCL 官方说明。（S-009）

2026-10-20 17:55

MineBBS 发布情况说明与临时管制

称 PCL、HMCL 等因合规性原因关停下载，明确与网易、Mojang、Microsoft 无直接关联，并称未发现与具体服务器、资源或作者有关的迹象；警告“修复版启动器”风险。（S-007）

2026-10-20 17:56—20:47

PCL CE 限制大陆安装功能

PR #3673 称“受近期事件影响……暂时禁止中国大陆地区用户使用 Minecraft 本体、整合包的下载、安装与补全功能”，18:24 合并，20:47 发布正式版 2.15.1。（S-005、S-006）

2026-10-21 09:58

“家长举报”起因被标题化

游民星空称“据说明”事件起因是未成年玩家私服充值后被家长举报，PCL 因提供下载游玩私服的方式受牵连。文中没有举报回执、交易记录、监管文书或具名采访，因果仍属争议。（S-010）

2026-10-21 20:00

首轮核查与补充复核完成

三款启动器均无恢复下载的新版本；HMCL 稳定版未跟进，PCL 与 PCL CE 最新版仍为 2.99.0.0 与 2.15.1；未检索到监管机关公开文书。官方设计保留已安装版本启动，但未逐版本运行验证。（S-001、S-004、S-005）
